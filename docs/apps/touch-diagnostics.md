# Touch Diagnostics

Status: `ready`

Source route: local Waveshare diagnostic sketch.

## Waveshare Controls

- Touch anywhere to show remapped FT3168 coordinates.
- Use the display to confirm SH8601 orientation and touch calibration.
- Press BOOT to return to the launcher.

## SD Data

No runtime SD data is required.

## Port Notes

This app is kept as a small hardware sanity check before testing larger catalog
apps.
