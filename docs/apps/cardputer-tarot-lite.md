# Cardputer Tarot

Status: `lite`

Source route: native Waveshare touch Tarot Lite app.

## Waveshare Controls

- Tap `One Card` or `Three`.
- Swipe left/right to redraw the current spread.
- Press BOOT or hold BOOT to return to the launcher.
- Serial fallback: `one`, `three`, `home`.

## SD Data

Readings append to `/waveshare-os/tarot/history.csv`.

## Port Notes

This keeps the full 78-card deck concept while replacing Cardputer keyboard
controls with simple touch draws.
