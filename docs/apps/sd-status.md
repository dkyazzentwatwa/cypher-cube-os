# SD Status

Status: `ready`

Source route: local Waveshare diagnostic sketch.

## Waveshare Controls

- Tap or press BOOT to return to the launcher.
- Read card type, size, and catalog path status on screen.

## SD Data

Reads `/waveshare-os/apps/apps.json` and reports SD_MMC card status.

## Port Notes

Use this first when app installs fail or the launcher cannot see the manifest.
